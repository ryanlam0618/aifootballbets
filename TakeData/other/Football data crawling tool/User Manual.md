# ⚽ 足球比賽球員數據爬取工具 使用說明

## 📋 概述

本工具是一款專門用於自動爬取足球比賽技術統計和球員表現數據的桌面應用程式。它可以從 Titan007 網站獲取比賽的基本數據、技術統計數據以及球員詳細數據，並將這些數據保存到 Excel 文件中。

## 🚀 功能特點

- **自動化數據爬取**：自動獲取比賽技術統計（角球、射門、控球率等）
- **球員數據收集**：提取球員個人表現數據（射門、傳球、評分等）
- **多日期批量處理**：支持批量爬取指定日期範圍內的比賽數據
- **聯賽篩選功能**：可選擇特定聯賽進行數據爬取
- **實時進度監控**：提供可視化進度條和運行日誌
- **智能數據合併**：將比賽數據、技術統計和球員數據合併到同一個 Excel 文件

## 🛠️ 系統要求

- Python 3.7 或更高版本
- Chrome 瀏覽器
- Windows 作業系統（推薦）

## 🎯 使用方法

### 1. 啟動程序

雙擊運行 `比賽球員數據爬取工具繁体版.py` 或在命令行中執行：

```bash
python 比賽球員數據爬取工具繁体版.py
```

### 2. 設定參數

#### 日期範圍設定
- **開始日期**：選擇要爬取數據的起始日期
- **結束日期**：選擇要爬取數據的結束日期
- 默認設置為當日前7天到當日

#### 聯賽篩選（可選）
- 在「聯賽篩選」欄位中輸入要爬取的聯賽名稱
- 支持多個聯賽，用逗號（,）、中文逗號（，）或空格分隔
- 範例：英超,西甲,意甲 或 英超 西甲 德甲
- 如留空則爬取所有聯賽

### 3. 開始爬取

點擊「🚀 開始爬取」按鈕開始數據爬取過程

### 4. 監控進度

- 查看進度條了解爬取進度
- 觀察運行日誌了解詳細狀態
- 進度顯示包括：
  - 整體進度百分比
  - 處理的日期數量
  - 已處理的比賽場次

### 5. 停止爬取

如需提前停止，點擊「⏹️ 停止爬取」按鈕

## 📁 輸出文件結構

爬取完成後，數據將保存在 `data` 文件夾中：

```
data/
├── YYYYMMDD_主隊_vs_客隊.xlsx
```

每個 Excel 文件包含三個工作表：

### Match Technical Stats（比賽技術統計）
- 包含兩隊的技術統計數據
- 涵蓋角球、射門、控球率等27項指標

### Player Data（球員數據）
- 包含每名球員的詳細表現
- 包括射門、傳球、評分等12項個人指標

### Match Basic Data（比賽基礎數據）
- 比賽的基本信息
- 包括日期、聯賽、比分等9項基本信息

## ⚠️ 注意事項

1. **網絡穩定性**：確保網絡連接穩定，避免爬取過程中斷
2. **反爬機制**：程序已加入隨機延時和人類行為模擬，但仍需適度使用
3. **數據準確性**：爬取的數據僅供參考，實際數據可能因網站變化而有所不同
4. **資源消耗**：大批量爬取會消耗較多系統資源，建議合理設置日期範圍
5. **網站政策**：請遵守目標網站的使用條款，不要過度頻繁訪問

## 🔍 常見問題

### Q: 為什麼沒有找到 Chrome 瀏覽器？
A: 請確保系統中已安裝 Chrome 瀏覽器，或手動設置 Chrome 路徑。

### Q: 爬取過程中出現錯誤怎麼辦？
A: 檢查網絡連接，查看運行日誌中的具體錯誤信息，可能需要重新啟動程序。

### Q: 為什麼某些比賽數據沒有獲取到？
A: 可能是該比賽沒有完整數據，或是網站結構發生變化導致解析失敗。

### Q: 如何提高爬取速度？
A: 可以減少同時處理的日期範圍，或優化網絡環境。
